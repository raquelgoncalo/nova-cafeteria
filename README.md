# ☕ Nova Cafeteria

Website responsivo desenvolvido para uma cafeteria, com foco em apresentação visual, organização de conteúdo e adaptação da interface para diferentes tamanhos de tela.

## Sobre o projeto

O projeto foi desenvolvido para praticar conceitos de desenvolvimento Front-end, utilizando HTML5 e CSS3 na construção de uma página moderna e responsiva.

A interface foi estruturada para proporcionar uma navegação simples e uma boa experiência tanto em desktop quanto em dispositivos móveis.

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-000?style=flat-square&logo=html5)
![CSS3](https://img.shields.io/badge/CSS3-000?style=flat-square&logo=css3)

## Funcionalidades

- Layout responsivo
- Estruturação semântica com HTML5
- Estilização com CSS3
- Adaptação para dispositivos móveis
- Organização visual de conteúdo
